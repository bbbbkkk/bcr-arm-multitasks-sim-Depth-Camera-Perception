# bcr-arm-multitasks-sim-Depth-Camera-Perception

ROS 2 and Gazebo simulation workspace for the BCR arm with MoveIt pick-place demos,
RGB-D camera perception, detected block pose publishing, and a perception monitor GUI.

## Main additions in this version

- External fixed RGB-D camera in simulation
- Red / blue / purple block pose detection
- Place-area pose detection
- Perception-driven pick and place demo
- Block pose monitor GUI

## Packages

- `bcr_arm_demo`
- `bcr_arm_description`
- `bcr_arm_gazebo`
- `bcr_arm_moveit_config`
- `bcr_arm_ros2`
